Server

Used by tflens serve from its next start; the --host, --port and --allow-remote flags override them. TFLens has no authentication: anyone who can reach a non-loopback address can read the analyzed source code, so it refuses to listen on one unless this is ticked (or --allow-remote is given).

Runs

Applied after every analysis: older runs are deleted together with their out/ directory. The model JSON of a run is kept on disk only; the database stores its path and summary counts.

TFLens analyzes Terraform statically and read-only: no terraform binary, no AWS API calls, no requests from the browser to anywhere but this server. The only network operation is the Sync of a git repository (a shallow clone), and only when you click it.
